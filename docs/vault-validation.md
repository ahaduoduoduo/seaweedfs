# Vault 本地场景验证

日期：2026-10-15。环境：macOS arm64，真实 `weed vault` 和 OpenList 网关进程，115 边界使用磁盘模拟器。NAS 生产服务和真实 115 没有参与测试。

## 数据与并发

- 基础数据集 243 个对象：60 篇正文及配图、120 张约 2.16 MiB 的 JPEG、约 37.5 MiB 的 MP4、512 MiB 的备份文件，以及 9 MiB 续传文件。
- 3 个业务空间，6 个并发写入客户端。
- Python 范围读取与 Node CLI 完整大文件下载同时运行。
- 2 个浏览器标签页同时读取同一相册块，另一个 CLI 同时读取视频。
- 浏览器额外提交一个正文对象；故障阶段额外提交一个对象，最终共有 245 个当前对象。

## 验证结果

| 场景 | 结果 |
|---|---|
| 上传 4 MiB 后 SIGKILL，重启续传 | 完整摘要一致；启动未访问云目录 |
| JSON 和附件原子提交、旧 revision 并发更新 | 冲突返回 409，其他对象没有部分提交 |
| 关联打包 | 同一笔记正文和配图位于同一 pack |
| 512 MiB 全量下载及跨块范围 | Python 与 JavaScript 独立客户端得到相同明文 |
| 网页上传、正文/图片预览、390px 移动布局 | 浏览器交互通过，无横向溢出 |
| 两标签页共享缓存 | 同一个图片 pack 只触发一次云下载 |
| 浏览器跨域拒绝 | 结束旧许可后申请新许可，由 NAS 中转密文并在客户端解密 |
| Vault 与 OpenList 数据库全部删除 | 通过票据和恢复密钥重建，并读取原有正文和大文件范围 |
| 定时检查点与版本 checkpoint 标记 | 自动生成成功，恢复标记对应已完成检查点 |
| 上传失败后进程重启 | 保留本地已提交数据，延迟重试成功 |
| CDN 返回 405，随后重启 Vault | 账户冷却保持，元数据查询继续正常 |
| 篡改票据签名 | 导入回执和创建目标数据库之前拒绝 |

代表性通过运行在恢复之前记录：22 次上传、18 次 CDN 下载、0 次远端目录查询、0 次凭据泄漏，最大同时下载数为 1。模拟器将下载启动间隔缩短为 1 秒以加快测试，断言相邻启动至少相隔 900 ms；部署默认保持 5 秒间隔。目录数据库及 WAL 合计约 4.45 MiB，本地正文和 pack 暂存已清空。

自动化入口为 `test/vault/scenarios.py`。每次运行的精确计数、下载时间序列和截图保存在 `build/vault-test-results/`；GitHub 的 `vault-scenario-results` 构建附件保存 Linux x86 的对应结果。失败场景是实际服务进程的错误注入，未替代真实服务实现。
